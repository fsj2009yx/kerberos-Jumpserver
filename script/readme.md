# Script

Certificate initialization scripts:

- `script/v_server/init_cert.py`
  - Generates `keys/v_priv.json`
  - Generates `certs/v_cert.json`

- `script/client/init_cert.py`
  - Prompts for a number when no argument is provided.
  - `1` generates the `CLIENT_1` key/certificate files, `2` generates `CLIENT_2`, etc.
  - Generates the numbered client private key under `client/keys/`.
  - Generates the numbered client certificate under `client/certs/`.
  - Generates the server-side certificate under `certs/clientN_cert.json`.
  - Updates active proxy aliases `client/keys/client_priv.json` and `client/certs/cert_client.json` by default.

Certificates already contain public keys, so standalone `*_pub.json` files are not generated by default. Use `--write-public-json` when you explicitly need them for debugging.

Examples:

```bash
client/proxy/.venv/bin/python script/v_server/init_cert.py
client/proxy/.venv/bin/python script/client/init_cert.py 1
client/proxy/.venv/bin/python script/client/init_cert.py
client/proxy/.venv/bin/python script/client/init_cert.py 2 --write-public-json
```
