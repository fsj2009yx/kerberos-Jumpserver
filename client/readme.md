# Client

how to run:
`/proxy/`: is the client API -- first install (`py -m pip install -r requirements.txt`) then run the client API (`py main.py`). make sure to also run the go server (main server)

`/client`: is the frontend API -- first install (`npm install`) then do to run the client frontend. `npm start` for making Electron appear, `npm dev` for only the frontend part (in chrome) (not connected to API).

you have to run all 3 servers :)
